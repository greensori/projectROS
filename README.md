x조리 프로세스는 크게 총 5단계로 구성이 되는거고

아래 순서대로 일이 처리되는 것이야

조리단계에서 각 메뉴들은 총 5개의 타이머를 가져야해

1. 총 조리시간을 기록하는 타이머
2. 앞면의 총 조리시간을 기록하는 타이머(최대 6분)
3. 뒷면의 총 조리시간을 기록하는 타이머(최대 6분)
4. heat unit 조리시간을 기록하는 타이머(최대 3분)


4단계에서 조리중 위상변화는 4번의 조리시간을 기록해서 위치를 변화시켜야 하는 거고
총 조리시간을 6분을 초과하는 경우에도 위상을 변화시켜야해

하지만 조리시간을 채워서 완료된 메뉴가 있는 경우 새로운 메뉴가 2단계로의 진입은 막아야 함.

처리 순서 정리(우선순위)
├── 1순위 : 1단계  #독립적으로 작동
│   ├── 조건1 : 주문완료되어 대기중인 요리가 있을 것

│   └── 실행

│   ├── 조건4 : stm_unit_2가 픽업전 위치에 위치한 경우 
│   └── 실행

│   ├── 조건3 : 1단계 공정이 완료대기 상태일것
│   └── 실행
